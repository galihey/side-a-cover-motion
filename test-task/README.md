# Страница тестового задания

Публичный адрес: https://galihey.github.io/side-a-cover-motion/test-task/

Содержание: два лендинга SIDE A и SIDE B, разбор ChatGPT, Google Gemini с Nano Banana и Suno, идея своего приложения, блок обо мне и три реальных промпта.

Текстовые исходники находятся рядом с собрать_страницу.py. Сборка: python собрать_страницу.py. Скрипт также обновляет общую Markdown-версию, автономный HTML и ZIP в родительской папке. Старые материалы сохранены в «Архив до редактуры».

Для публикации используются index.html, styles.css и assets. Сайт статический, без форм и серверной части. Имя шрифта Onest, лицензия в assets/OFL-Onest.txt.

Проверены мобильные ширины 320 и 390 px, компьютерная версия, раскрытие промптов и адреса обеих крупных ссылок. Физический iPhone не использовался.

Данные о функциях, ценах и рейтингах проверены 3 ноября 2026 года. Источники стоят рядом с соответствующими фактами. Причины роста и предложения улучшений являются авторскими гипотезами.
