ИИ-помощник на сайте

Посмотреть ИИ-помощника ↗Открыть демо

Демо · 6 проектов

Как вам это поможет?

Посетитель задаёт вопрос, а ИИ находит ответ по материалам вашего сайта.

С помощью ИИ сделал локального помощника с RAG-подходом: сначала он находит нужные фрагменты в описаниях моих проектов, затем отвечает на вопрос и показывает цитаты. Добавил сравнение опыта с требованиями вакансии. Весь корпус в каждый запрос не передаётся.

Для поиска использовал BM25 и embeddings, для ответов — gpt-4.1-mini через OpenAI API. Сервер на FastAPI проверяет точное совпадение цитат с найденными фрагментами. Приватные документы не индексируются.

Python · FastAPI · OpenAI API · BM25 · embeddings · SQLite · HTML/CSS/JavaScript
